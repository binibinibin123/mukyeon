# Changelog

All notable changes to this project are listed here. The format follows

## [0.1.0] - 2026-11-21

First public release.

### Added
- Ink-wash koi pond that runs behind the desktop icons on Windows 10/11.
- Nine carp drawn as bendable ink strips, with soft shadows and a swimming tail.
- Water simulation: ripples bend the picture, and the cursor and fish tails stir ink into the paper.
- Fish follow the cursor: each notices it at its own pace, swims over, circles at its own distance,
  and darts away when the cursor is flicked at them.
- Pauses rendering while a full-screen app covers the desktop; restores the normal wallpaper on exit.
- System tray icon with a Quit entry.
- `--demo` mode with a scripted cursor, used to record the demo video in CI.
